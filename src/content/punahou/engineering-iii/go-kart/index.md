# Chassis!

This is the base shape of our chassis. As we continued to work on the project we added more cross beams and plates where we needed.

# Problems

While building the Chassis we had many problems with our brackets. The brackets we used had weird holes that were slightly off-set. This made drilling hard because there was zero symmetry causing us to redo bars multiple times.
